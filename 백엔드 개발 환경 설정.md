# **백엔드 개발 환경 설정**



###### **1. Conda 환경 생성 (최초 1회)**

conda create -n ieum_backend python=3.12

conda activate ieum_backend

python --version



Python 3.12.x가 출력되면 정상입니다.

===================================================================

###### **2. 라이브러리 설치**



가상환경이 활성화된 상태에서 실행합니다.



pip install -r requirements.txt



======================================================================

###### **3. 새로운 라이브러리 설치 시**



새로운 라이브러리를 설치한 경우 requirements.txt도 함께 업데이트해야 합니다.



pip install <라이브러리명>



pip freeze > requirements.txt



git add requirements.txt

git commit -m "Update requirements"

git push



다른 팀원은 아래 명령으로 최신 환경을 적용합니다.



git pull

pip install -r requirements.txt



============================================================================

###### **4. 작업 전 반드시 가상환경 활성화**



라이브러리 설치 및 서버 실행 전 반드시 아래 명령을 실행합니다.



conda activate ieum_backend



프롬프트 앞에 아래처럼 표시되면 정상입니다.



(ieum_backend)





=========================================================================

###### **5. 현재 사용 중인 Python 확인**

python --version



또는 (Windows)



where python



예시



(ieum_backend)

Python 3.12.13



=====================================================================

###### **6. 현재 활성화된 Conda 환경 확인**

conda info --envs



예시



# conda environments:



base

ieum_backend    *



*가 붙은 환경이 현재 활성화된 환경입니다.



**주의**: base 환경에서 작업하지 말고, 반드시 ieum\_backend 환경을 활성화한 후 작업해주세요.

===========================================================================

###### **7. 서버 실행**

uvicorn app.main:app --reload



실행 후 아래 주소에서 확인할 수 있습니다.



API : http://127.0.0.1:8000

Swagger : http://127.0.0.1:8000/docs

ReDoc : http://127.0.0.1:8000/redoc



===========================================================================

###### 📌 **개발 순서**



1. git pull
2. conda activate ieum\_backend
3. pip install -r requirements.txt (requirements.txt가 변경된 경우)
4. uvicorn app.main:app --reload
